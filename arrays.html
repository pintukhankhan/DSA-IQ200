01 · STRUCTURE DEEP DIVE

Arrays — think in memory, not boxes.

An array is a contiguous region of elements. The real skill is not memorizing “O(1) access”; it is deriving why the address is computable, when shifting is unavoidable, and how locality changes performance.

IQ 200 MODEL

Address equation

address(A[i]) = base(A) + i × element_size
10× question: If an array starts at address 1000 and each integer occupies 4 bytes, what is the address of A[17]?
1000 + 17×4 = 1068. The key idea is that indexing is arithmetic, not a search.

Deep model: insertion

Suppose [10,20,30,40] and we insert 25 at index 2. The values 30 and 40 must move one position right. One insertion can therefore be O(n). The important invariant is: after insertion, the relative order of all untouched elements remains unchanged.

# conceptual shift
for i from n-1 down to index:
  A[i+1] = A[i]
A[index] = x

Deep model: deletion

Deleting A[k] creates a hole. To preserve contiguous representation, elements after k shift left. Worst case: delete the first element → move almost everything. That is why dynamic arrays distinguish amortized O(1) append from O(n) middle deletion.

Trap: “Array deletion is O(1)” is only true for a special unordered-delete trick where you replace the removed item with the last element.

Cache locality

Contiguous elements tend to be cache-friendly. Sequential scans exploit spatial locality, often making arrays dramatically faster than pointer-heavy structures even when asymptotic complexity matches.

Dynamic arrays

Capacity grows geometrically. Most appends are cheap; occasional resize copies n elements. Across many appends, total copying is O(n), giving amortized O(1) append.

IQ 200 invariant

At every valid index i, the element belongs to the contiguous block and its address equals base + i·size. Break contiguity and the constant-time indexing proof disappears.

SOCRATIC CHECK

Do not memorize. Derive.

Why does binary search require sorted order? Why can a hash table beat an array for lookup? Why does a cache care that values are adjacent? Answer each in words before revealing the model answer.

Sorted order: it lets one comparison eliminate an entire region.

Hash table: a hash function maps a key toward a bucket, avoiding a full scan on average.

Cache: hardware fetches memory in lines, so nearby elements are likely already loaded.
