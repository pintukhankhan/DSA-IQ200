08 · REASONING

Dynamic Programming — compress repeated work.

DP is a method for problems with overlapping subproblems and optimal substructure. The real skill is designing the state, transition, base cases, and evaluation order.

State

Define exactly what dp[i] or dp[i][j] means. If the state cannot be stated in one precise sentence, the solution is not ready.

Transition

Derive how the current state depends on smaller states. Then prove that every dependency has already been computed.

IQ 200 test: Can you change the state dimension without changing the underlying recurrence? If yes, you understand the abstraction instead of the code.
