Stacks — LIFO as a reasoning tool.

A stack exposes one disciplined end. Push and pop happen at the top, making it ideal for recursion, undo systems, expression parsing, and depth-first exploration.

O(1)push
O(1)pop
LIFOlast in, first out
IQ 200: A stack is not merely a data structure; it is a constraint that makes the most recent unresolved decision the next one to process.

Classic applications

Function calls use a call stack. Parentheses matching uses a stack of unmatched opening symbols. DFS uses a stack explicitly or implicitly through recursion.

Interview invariant

Every item below the top remains inaccessible until all items above it are removed. If an algorithm needs arbitrary access, a stack is probably the wrong abstraction.

Micro challenge

Push A, B, C. Pop once. Push D. What is the next popped value?
