04 · STRUCTURE

Queues — FIFO and controlled flow.

Queues process the oldest waiting item first. They model scheduling, breadth-first search, network buffers, and producer-consumer systems.

IQ 200: In BFS, the queue is what forces exploration by distance layers: nodes discovered earlier are expanded earlier.

Correct queue design

With an array, removing from index 0 can be O(n) if every remaining element shifts. A circular buffer or two-ended indexing can make enqueue/dequeue O(1).

Priority queue ≠ queue

A priority queue chooses the highest/lowest priority, not the oldest arrival. It is usually implemented with a heap and supports O(log n) insertion/removal.
