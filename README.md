# DSA IQ 200 — Intelligence Laboratory v2

This version is rebuilt around the supplied professional dashboard reference.

## Features

- Professional dark IDE-style dashboard
- Responsive sidebar
- Binary Search visual execution
- First / Previous / Play / Next / Last / Reset
- Live left / mid / right state
- State Inspector
- Code Editor panel
- Complexity Analyzer
- Student Dashboard
- IQ 200 Arena
- AI Teacher panel
- Socratic question + answer
- Browser text-to-speech explanation
- Mobile navigation
- GitHub Pages compatible
- All assets stored locally

## Deploy

Upload the entire folder to GitHub.

**Settings → Pages → Deploy from branch → main → /root**

Do not upload only `index.html`. The `css`, `js`, and `assets` directories are required.

## Important

All references use relative paths:

```text
css/app.css
js/app.js
assets/logo.svg
assets/favicon.svg
assets/teacher.svg
```

Therefore the project works correctly when hosted at:

```text
https://USERNAME.github.io/REPOSITORY/
```
