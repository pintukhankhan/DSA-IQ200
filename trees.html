05 · STRUCTURE

Trees — recursion with structure.

A tree organizes nodes hierarchically. The core reasoning pattern is to solve a problem on a node by solving smaller problems on its children.

solve(node) = combine(solve(left), solve(right), node)
Key distinction: A binary tree only limits children to at most two. A BST adds an ordering invariant.

Traversal

Preorder: node-left-right. Inorder: left-node-right. Postorder: left-right-node. Level order uses BFS.

BST invariant

For every node, values in the left subtree are smaller and values in the right subtree are larger, under the chosen duplicate policy.

Height matters

A balanced BST has height O(log n). A degenerate chain has height O(n). The same operations can therefore have radically different performance.
